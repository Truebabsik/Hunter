# Решения дизайн-сессии 2026-09-24

Документ фиксирует промежуточные результаты штурма открытых вопросов спецификации `dizain_hunter.md`. Каждое решение получено через multi-choice brainstorming с пользователем. Большинство из них — **дизайн-гипотезы**, ожидающие верификации симулятором или playtest'ом.

**TL;DR:** зафиксирована двухслойная архитектура экономики (A = путь к Легенде, B = после Легенды); согласован узкий A-narrowed must-buy; предложены правки ранних цен и трофеев (β.1+β.2); переписаны эталоны советов Старика под принцип «направление + намёк»; зафиксирован **D17: «Громун дальним — экзамен + хроника гильдии»** — третий канал soft hint через микро-заметки других охотников; зафиксирован **D19: «Стены чтения → нарративная обратная связь по результату удара»** — каждый удар отражается в прозе через резист / уязвимость, без новых UI-сигналов; зафиксирован **D20: «Восстановление ортогонального оружейного списка»** — каталог пересобран под шесть имён (Молот / Меч / Копьё / Лук / Праща / Чакрам), закрывающих матрицу 3×2 без пробелов; концепт скорости оружия и бонус оружия к инициативе сняты; A-narrowed сужен до «Молот + Лук» (55 монет).

---

## 1. Цель и базовые параметры

### 1.1 Цель playthrough'а

Стать **Легендой** — убить Ламента. Не «купить всё дерево», не «собрать полную коллекцию». Это меняет фокус дизайна:

- Экономика балансируется под must-buy пути к Ламенту, а не под «полную прокачку».
- После Легенды остаётся пространство для расширения (см. слой B).

### 1.2 Игровой цикл

```
квест → охота → возвращение в город → трата ресурсов → прокачка →
ранг ↑ → доступ к более высокоранговым монстрам → повтор
```

Общий бюджет — ограниченное количество дней, укладывающееся в ~10–15 охот. Подробнее — §8.8 спецификации (`~N дней`, см. также §1.3.1).

### 1.3 Длина пути

Принято текущее значение §12.12 — **~10–15 охот** от Ученика до Легенды.

## 2. Архитектура экономики: A/B split

Экономика разделяется на два непересекающихся по назначению слоя:

| Слой | Назначение | Когда открывается |
|--|--|--|
| **A** — must-buy для пути к Легенде | Минимальный набор снаряжения и навыков, позволяющий стабильно побеждать Лагента | Доступен сразу (стартовый капитал формирует кривая §12.10) |
| **B** — расширения второго цикла | Всё остальное: руна льда, дополнительные типы оружия, функциональный плащ, амулет стойкости, косметика, история Старика как платный контент | Разблокируется статусом Легенды |

**Почему так:** в текущей спеке авторская оценка «обязательные ~1200» (§12.10) была неточной — реальный must-buy при условии «купить всё дерево навыков + все руны + 6 типов оружия» съедает >1500 монет против 620 кумулятивного дохода. Split A/B позволяет сохранить долгосрочный потолок развития без удушения основного playthrough'а.

## 3. Слой A: must-buy (A-narrowed)

Состав после brainstorm:

| Категория | Позиции | Σ цена |
|--|--|--|
| Оружие | Клинок + Лук + Арбалет + Дробящий *(D17)* → **Молот + Лук** *(D20, минимум для экзамена Громуна)* | 110 → **55** |
| Руны | Огонь + Яд (Лёд не включается — нужен только против Хруза, опционально) | 85 |
| Броня | Лёгкая + Тяжёлая | 55 |
| Советы Старика | 6 платных советов (Шипун…Ламент). Бесплатный Хруз — ступень Ученик | 80 |
| Навыки (Чтение L1+L2+L3) | Опорный/Двойной/Тройной сигнал | 120 |
| Навыки (Оружие L1+L2+L3) | +1/+2/+3 урон | 140 |
| Навыки (Выживание L1+L2+L3) | +1/+2/+3 броня | 140 |
| **Σ must-buy (as-is)** | | **730 → 675** (после D20) |

После применения гипотез β.1+β.2 (см. §4 ниже): must-buy ≈ **693**.

**Примечание (D20, 2026-09-24).** Каталог оружия восстановлен по авторской памяти и пересобран под ортогональную модель 3×2: шесть имён (Молот / Меч / Копьё / Лук / Праща / Чакрам), каждое однозначно задаёт пару (дальность, базовый_тип). Концепт скорости оружия и бонус оружия к инициативе сняты (подробности в `delta-hunter-2026-09-24.md` блок D20). Старые имена (Клинок / Арбалет / Дробящий / Костяной гарпун / Костяной залп) **больше не входят в must-buy**:

- «Молот» = бывший «Дробящий ближний» (5 урона, 30 монет);
- «Копьё» = новое (колющий ближний, 4 урона, 25 монет); раньше такого типа не было;
- «Праща» и «Чакрам» — два новых дальних оружия (дробящее и режущее соответственно), покрывают освободившиеся ячейки матрицы.

Остальные четыре оружия (Меч / Копьё / Праща / Чакрам) **доступны в магазине**, но **не обязательны** для победы над Лагентом и не входят в A-narrowed. Полный набор всех шести типов ≈ 155 монет (30+20+25+25+15+40).

Расход must-buy на оружие снижается с 110 до **55 монет** (−55), Σ с 730 до **675** (−55). Для сравнения, после применения β.1+β.2 (если когда-либо будет принято): оценка must-buy ≈ **638**.

## 4. Гипотеза β.1 + β.2 (ценовая и трофейная правки)

### 4.1 β.2 — снижение ранних цен (~20%)

Цены опускаются для предметов, покупаемых в фазах Подмастерье → Охотник → начало Ветерана. Поздний тир (Тройной опорный, +3 урон, +3 броня, Руна_яд, Тяжёлая броня) остаётся как был.

| Item | Было | Стало | Δ |
|--|--|--|--|
| Клинок | 20 | 16 | −4 |
| Лёгкая броня | 15 | 12 | −3 |
| Опорный сигнал | 20 | 16 | −4 |
| +1 урон | 25 | 20 | −5 |
| +1 броня | 25 | 20 | −5 |
| Совет Шипуна | 5 | 4 | −1 |
| Лук | 25 | 20 | −5 |
| Арбалет | 35 | 30 | −5 |
| Дробящий | 30 | 25 | −5 |

### 4.2 β.1 — повышение ранних трофеев

| Монстр | Было (mid) | Стало (mid) | Δ |
|--|--|--|--|
| Хруз | ~12 | ~21 | +9 |
| Шипун | ~16 | ~23 | +7 |
| Громун | ~28 | ~35 | +7 |

### 4.3 β.3 — повышение средне-поздних трофеев (выявлено симулятором)

После прогонов стало ясно, что только β.1+β.2 недостаточно: на этапе Ветеран возникает дефицит ~95 монет из-за скопления крупных покупок (Руна_яд 65, +3 урон 70, Тройной опорный 60, +2 урон/броня по 45).

Решение — поднять средне-поздние трофеи:

| Монстр | Было (mid) | Стало (mid) | Δ |
|--|--|--|--|
| Скорб | ~47 | ~70 | +23 |
| Пепел-Мать | ~55 | ~80 | +25 |

Это согласуется с авторской рекомендацией §12.10 («Доход × 1.65»), но в более мягкой форме: A-narrowed с β.1+β.2+β.3 даёт множитель ≈×1.24 к исходному доходу спеки (620 → 767), при этом сохраняя must-buy 730 → 693.

### 4.4 Финальная разбивка дохода по этапам

Базируется на §12.12 спецификации; повышена за счёт β.1+β.3:

| Этап | income_delta | кумулятивный |
|--|--|--|
| Ученик → Подмастерье | 22 | 22 |
| Подмастерье → Охотник | 75 | 97 |
| Охотник → Ветеран | 140 | 237 |
| Ветеран → Мастер | 335 | 572 |
| Мастер → Легенда | 195 | 767 |

### 4.5 Отложенные покупки (deferral'ы)

Чтобы пройти cash-flow без радикального повышения цен снаряжения, часть предметов перенесена на более поздние дедлайны:

| Предмет | Изначальный дедлайн | Новый дедлайн | Причина |
|--|--|--|--|
| +2 урон (Оружие L2) | Охотник | Ветеран | Громуна/Тлеуна бьём на +1 |
| +1 броня (Выживание L1) | Подмастерье | Охотник | Шипуна бьём без дополнительной брони |
| Лёгкая броня | Подмастерье | Охотник | Громуна бьём уворотом |
| Дробящий | Ветеран | Мастер | Пепел-Мать бьём Клинком/Луком |
| Тяжёлая броня | Ветеран | Мастер | Достаточно лёгкой до боя с Ламентом |

Эти deferral'ы **сдвигают расходы на более платёжеспособные этапы**, не убирая must-buy из общего списка.

### 4.6 Результат симулятора (`tools/economy_sim.py`)

```
PASS: total income=767, spent=693, buffer=74

Ученик→Подмастерье          +22     баланс    22   spent      0
Подмастерье→Охотник         +75               97           66
Охотник→Ветеран            +140              237          132
Ветеран→Мастер             +335              572          335
Мастер→Легенда             +195              767          160
```

Запас 74 монеты позволяет опциональные траты: руна_льда (60), или повторный найм советов Старика, или лечение после тяжёлых боёв.

## 5. Советы Старика — правило формулировки

§14.3 [Нарратив]: «не слишком ли полезен? Рекомендация: он даёт направление, а не решение.» Эта рекомендация существовала в спеке, но примеры §9.3 ей противоречили (давали почти готовые сценарии «капюшон встаёт → бросит жало»). Штурм 2026-09-24 закрепил конкретный принцип.

### 5.1 Правило

> Совет Старика содержит:
> - направление наблюдения (что слушать / что видеть);
> - намёк на оружие, тип урона или уязвимость (**один** элемент);
> - атмосферную метафору.
>
> Совет НЕ содержит:
> - точных соответствий «сигнал → действие»;
> - прямых команд «бей туда-то, тогда-то»;
> - указания на конкретный раунд или фазу.

### 5.2 Эталоны тона (утверждены пользователем)

**Хруз** *(бесплатный)*
> «Хруз. Береговой. Тяжёлый, но резкий. Слушай берег — ракушки скажут первыми. Когда затихнет — поздно. Бей там, где панцирь мягок. Лёд здесь не случаен.»

**Шипун**
> «Шипун. Скользун. Быстр. Видишь движение — не верь ему; жди настоящего. Капюшон обманет. Тело его выдаёт — жги, когда развернётся.»

**Ламент**
> «Ламент. Пожиратель. Не ищи закономерностей — он их сам ест. Жди. Тишина перед ним громче крика. Услышишь — бей ближе. Яд ему в тягость, как никому.»

### 5.3 Экономический эффект

Полезность совета снижается с ~70% (готовый сценарий) до ~30% (soft hint). Это значит:

- Путь **без советов остаётся играбельным**: новичок может дойти до Ламента, опираясь только на собственное чтение сигналов.
- Путь **с советами даёт преимущество**: понимание типа урона и уязвимости на старте.
- В must-buy советы становятся **опциональными** (рекомендация, не обязательство).

## 6. Альтернативная цель — новая механика §10.8 (D15)

Штурм выявил механику, которая в спеке **частично существовала как побочная встреча (§10.7)**, но не была достроена: на пути к квестовому монстру игрок может встретить другого зверя того же ранга или ниже; после боя он выбирает — вернуться или продолжить охоту.

### 6.1 Решения

| Ось | Решение | Обоснование |
|--|--|--|
| Локация правила | Новая §10.8 «Альтернативная цель» | §10.7 сейчас нарративная; числовые таблицы ломают регистр. Чистое разделение. |
| Шанс подмены | **30 % плоско везде, кроме Ламента** (точки для парной балансировки в тестах) | Делает пре-боевую разведку осмысленной, не делает охоту хаосом. |
| Награда за победу над альтернативным | Слава ×0.5 от обычного, трофей ×0.5 продажной цены | Совпадает с уже принятым правилом §8.3 для побочных встреч; стимулирует целевые квесты. |
| Пост-боевой выбор | A: возврат (+1 день дороги обратно, квест не засчитан); B: продолжение («день охоты» уже оплачен) | Без AB-выбора подмена выглядит как ошибка; с ним — риск с весом. |
| Связь со следом | Фаза 2 сохраняет приметы цели до момента подмены; фаза 3–4 трансформируются под фактического противника | След работает как детектор рассогласования ожидания и реальности. |

### 6.2 Экономический эффект

Дополнительные монстры увеличивают средний доход на охоту (~+25–35 %), но платят половиной славы и трофеев. Netto:

- Если игрок 1 из 3 охот ловит подмену и возвращается — экономика остаётся в рамках базовой кривой ±10 %.
- Если продолжает — может получить двойную добычу, но рискует временем (−1 день за возврат не тратится только в варианте B).
- Трофеи ×0.5 слегка снижают давление must-buy; компенсируется ростом числа охот (если подмена затягивает игрока ещё на 2–3 дня, N=45 становится теснее).

Черновик лежит в `docs/superpowers/specs/dizain_hunter.md.append` (~110 строк). Содержит:

- Принцип и формулировку

## 7. Закрытие §14.3 — финальные правила нарратива (D16)

Штурм 2026-09-24 закрыл все три оси §14.3 (длина прозы, число фаз следа, роль следа) с учётом ранее принятых D13 (Старик = направление + намёк) и D15 (альтернативная цель).

### 7.1 Длина прозы — двойная шкала

| Категория | Базовая длина | Расширения |
|--|--|--|
| Боевая проза (текст в раунде) | 60–120 слов на раунд | +20–40 при идеальном чтении |
| След основной охоты | ~300–400 слов | +50 % при повторной охоте; +30 % при активной подмене (§10.8); до ×1.7 для Ламента |
| След побочной охоты (§10.7) | ~150–200 слов | Без расширений |
| Советы Старика | 2–4 строки (≈40–80 слов) | По уровню ранга: Мастер получает 1–2 предложения сверху |
| Досье | 1–3 предложения на вид | Полная версия при уровне «Мастерство» |

Принцип: **фиксированный базовый размер + опциональные расширения**. Это даёт стабильный ритм чтения и предсказуемость для UI/UX, сохраняя пространство для вариативности.

### 7.2 Число фаз следа — вариативно по типу охоты

| Тип охоты | Фазы | Комментарий |
|--|--|--|
| Основная (новая локация) | 4: выход → приметы → приближение → встреча | Как сейчас в §10.2 |
| Основная (повторная охота того же вида) | 4 (укороченные на 30 %) | Ритм узнавания |
| Элитный монстр / Ламент | 5: 4 базовых + предчувствие | Фаза 0 — короткое «предчувствие» перед выходом |
| Альтернативная цель (§10.8 подмена) | 2–3 | Зависит от того, на какой фазе игрок заметил расхождение |
| Побочная встреча (§10.7) | 2: тревога → встреча | Как сейчас |

Расширение до 5 фаз для элиты используется для подчёркивания веса; это дополнительный текстовый блок «предчувствия» (~100 слов), не изменяющий механику.

### 7.3 Роль следа — пре-боевая разведка (тип + стихия)

Главная функциональная роль следа:

> След — мягкая среда, сужающая пространство решений перед боем. Сообщает **тип зверя** (главное) и **стихию / дистанцию** (вторичное) через погодные условия, запахи, звуки, поведение других существ. Не выдаёт прямых соответствий «сигнал → действие». Окончательное решение остаётся за Подготовкой (§10.2 шаг 5\*) и досье.

Дополнительно след работает как **детектор рассогласования ожидания и реальности**:

- Если в момент подмены (§10.8) среда фазы 3 расходится со следом фазы 2 — игрок видит сигнал «что-то не так».
- На Подготовке он может сверить визуальное впечатление с досье фактического монстра и скорректировать экипировку.

### 7.4 Расширение на будущее: уход без боя при опознании подмены

Зафиксировано как **открытая возможность**, не реализуется немедленно:

- Если игрок по совокупности сигналов (след + Подготовка) убедился, что встретил альтернативного монстра — логично дать ему **возможность уйти без боя**.
- Это снижает цену ошибки и повышает значимость чтения среды.
- Требует решения: **где именно разрешать уход**?
  - На этапе Подготовки (после открытия досье)?
  - В первом раунде боя (один «бесплатный» круг на уход)?
  - После N ходов прозы без атаки?
- Также требует решения: **какие ограничения**?
  - Штраф по дням?
  - Потеря трофеев за «бой не состоялся»?
- Этот пункт помечается как кандидат на D17+ — отрабатывается **после** MVP.

### 7.5 Совместимость с другими решениями

| Решение | Связь с D16 |

## 8. Громун дальним — экзамен + хроника гильдии (D17)

Штурм 2026-09-24 закрыл открытый вопрос §12.11: что делать с ситуацией, когда игрок по незнанию бьёт Громуна только дальним оружием (урон 1/раунд → 15 раундов)?

### 8.1 Контекст задачи

Расчёт из §12.11:

- HP Громуна = 15, панцирь = 2, резист к дальнему = −2.
- Дальний бой (Арбалет+огонь): 1 урон/раунд → 15 раундов на убийство.
- Ближний бой (Клинок+огонь): 3 урона/раунд → 5 раундов.
- Разница ×3 — осознанно тупиковая для дистанции; единственный вид в МВФ, где смена оружия строго обязательна.
- Игрок узнаёт об этом **только из провалов**: либо долгий бой, либо смерть.

Были три кандидата (а)/(б)/(в); ни один сам по себе не устраивал:

- (а) снизить HP 15 → 12 — ломает авторскую характеристику вида;
- (б) запись в досье после первого дальнего удара — даёт прямую подсказку, противоречит D13 (soft hint);
- (в) «экзамен» — работает, но делает совет Старика обязательным, противоречит D13 (опциональность).

### 8.2 Решение

| Ось | Решение | Обоснование |
|--|--|--|
| Базовая стратегия | **(в) Оставить «экзамен»** | Авторская характеристика вида сохранена; нет поломки HP/reiist'а |
| Новый канал подсказок | **Хроника гильдии** (третий soft hint) | Не усиливает совет Старика (D13), не дублирует след (D16), даёт косвенный намёк через микро-нарратив |
| Арбалет | Остаётся в A-narrowed must-buy | Экзамен требует наличия обоих типов оружия; без Арбалета нет выбора «дистанция vs ближний» |
| Совет Старика для Громуна | Сохраняется текущий эталон из §9.3 (D13) | Мягкий намёк «иди ближе», не инструкция |
| След фазы 2 | Без изменений | Сигнал расхождения не нужен — экзамен работает через подбор инструмента, а не через детектор подмены |

### 8.3 Формат заметок в хронике

Каждая заметка — короткая нарративная фраза от имени одного из «мастеров-охотников» гильдии. Используются уже канонические имена Аскер, Мара, Кесс (см. §15.10 п.51 — истории Старика; заметки хроники переиспользуют этих же персонажей как нарраторов).

Шаблон:

```
{Имя}. {Вид}. {ключевое слово про инструмент или тактику}. {опционально — одна деталь}.
```

Примеры (привязка к видам):

- *«Аскер. Хруз. Лед, лед, лед. Камни мокнут первыми.»*
- *«Мара. Шипун. Жги, когда развернётся. Ближе — больнее.»*
- *«Кесс. Громун. Клинок, клинок, клинок. Дальше не подходи.»*
- *«Кесс. Тлеун. Топор найдёт щель в суставах. Яд — туда же.»*
- *«Мара. Скорб. Стрелы мало. Лучше слушать и бить ближе.»*
- *«Аскер. Пепел-Мать. Рой жжётся огнём, матка — ядом.»*
- *«Мара. Ламент. Не думай. Бей ближе, бей ядом.»

Это **не готовые решения**. Это атмосферные мнемоники, которые запускают догадку: «о, этот охотник сказал "ближе" — может, стоит попробовать?» Заметки не объясняют механику, не указывают тип урона напрямую и не дают команд.

### 8.4 Частота и доступность

Предварительная договорённость (до проверки playtest'ом):

- По одной заметке на каждого из 7 видов (минимум).
- Доступны с момента, как игрок впервые открывает Доску славы (§11.8). Не требуют победы над конкретным монстром — это память гильдии, не его собственный опыт.
- Все заметки читаются сразу, по запросу. Без gating'а по рангу.
- Имена мастеров-охотников (Аскер / Мара / Кесс) — статичные нарраторы; ротация заметок между ними не предполагается.

Конкретное количество заметок на вид (1 vs 2–3) и точный момент открытия — предмет playtest'а, а не ранней фиксации.

### 8.5 Трёхканальная модель soft hint

После D17 архитектура подсказок выглядит так:

| Канал | Что сообщает | Где живёт | Когда работает |
|--|--|--|--|
| **След** (D16) | Тип зверя + стихия/дистанция | Пре-боевая разведка, фазы 2–4 + Подготовка | До начала боя |
| **Совет Старика** (D13) | Направление + намёк на оружие/уязвимость | Город, платный найм | До боя; игрок покупает |
| **Хроника гильдии** (D17) | Микро-заметки других охотников с ключевым словом | Достопримечательности города, Доска славы | Свободно, без gating'а |

Ни один канал не даёт прямого решения «бей X оружием». Игрок должен **совместить все три** или **догадаться сам**, опираясь на досье.

### 8.6 Совместимость с ранее принятыми решениями

| Решение | Связь с D17 |
|--|--|
| D13 (Старик = soft hint) | Хроника дополняет, а не усиливает совет Старика. Совет остаётся тонким; хроника — фоновая подложка. |
| D15 (альтернативная цель) | Хроника работает и для альтернативных монстров: если игрок встретил Тлеуна вместо Громуна — он всё равно может прочитать заметки про обоих. Никакой рассогласованности нет. |
| D16 (след = пре-боевая разведка) | Хроника живёт вне следа. Она — **городской ресурс**, который можно прочитать до выхода на охоту; след — поле. |
| §15.10 п.51 (Старик = нарративный якорь) | Имена Аскер/Мара/Кесс каноничны для историй Старика; они же становятся авторами заметок хроники. Это **усиливает** мир-строительную функцию игры. |
| §11.8 Доска славы | Уже содержит записи типа «ДЕНЬ 21 +2 ПОБЕДА \| Инструмент: лук, огонь.». Заметки D17 ложатся рядом, но не дублируют фактологию боёв. |

### 8.7 Финальный статус открытого вопроса §12.11

Из четырёх кандидатов ((а)/(б)/(в) + новый комбинированный) выбран **(в) + новый канал**. Вариант (б) «запись в досье после первого дальнего удара» — **отклонён**, чтобы не нарушать принцип «подсказки не дают готовых ответов». Эту механику можно вернуть, если трёхканальной модели в playtest'е окажется недостаточно.

Зависимости:

- D17 требует §11.8 «Доска славы» как носителя (или альтернативный экран Хроники внутри §11). Готового UI нет — это будущая задача frontend'а.
- D17 не меняет must-buy Арбалета (30 монет, §3 настоящего документа).
- D17 не меняет расчёт HP/reiist'а Громуна (§12.11).

### 8.8 Стены чтения → нарративная обратная связь по результату удара (D19)

Штурм 2026-09-24 закрыл открытый вопрос §14.1: как помочь игроку заметить тупиковость выбранного оружия внутри боя — до того, как сработает адаптация вида (по умолчанию на 5-м раунде).

#### 8.8.1 Контекст

Игрок имеет минимум два типа оружия с самого старта и не может их потерять; если он не переключился вовремя — это его собственная ошибка, никакого «спасения» мы ему не даём. Но игра должна **честно отражать результат каждого удара**, чтобы у игрока был материал для размышления:

- Если удар попал в резист зверя — проза должна это показать.
- Если удар попал в уязвимость — проза должна это подтвердить.
- Если удар нейтральный — проза стандартная.

Это не новая механика, а использование **уже существующих данных о попадании в резист / уязвимость** (§12.5–§12.6) как основы для тональной обратной связи через текст.

#### 8.8.2 Решение

| Ось | Решение |
|--|--|
| Канал сигнала | Только нарратив боевой прозы (§11.x); никаких новых UI-маркеров, цветовых подсветок урона или авто-подсветки досье |
| Гранулярность | На каждый удар. Проза каждого раунда отражает результат текущего действия игрока |
| Источник фраз | Гибрид: общая грамматическая структура + лексика конкретного вида из §4.x + подстановка под комбинацию оружие × руна |
| Объём пула | Минимально покрыть все пары (оружие, руна, тип исхода) для 7 видов MVP |
| Новые данные | Не нужны — фидбек строится на уже известных формулах расчёта урона §15.10 п.54 |

#### 8.8.3 Структура фразы

Базовая схема пула:

```
[{вводная}] {носитель} {глагол-реакция} {дополнение}.
```

Слоты заполняются так:

- **`{вводная}`** — опциональная частица («едва», «наконец», «точно», «мимо»).
- **`{носитель}`** — имя существительное для текущего монстра, берётся из описания вида §4.x:
  - Громун → `камень`, `гарпун`, `наковальня`;
  - Хруз → `раковина`, `берег`, `волна`;
  - Шипун → `капюшон`, `тень`, `кобра`;
  - Ламент → `пустота`, `пасть`, `дыхание`.
- **`{глагол-реакция}`** — определяется исходом удара:
  - **Резист**: `смеётся`, `отбрасывает`, `гасит`, `заставляет рикошетить`, `равнодушен к`;
  - **Уязвимость**: `входит мягко`, `проваливается`, `расступается`, `обнажает`, `находит щель`;
  - **Нейтрально**: `попадает в плечо`, `скользит по чешуе`, `оставляет засечку` (стандартные пулы §§4.x).
- **`{дополнение}`** — под комбинацию оружие × руна:
  - Арбалет + огонь → `жжёт камень, но не плавит`, `пробивает искру, гаснет`;
  - Клинок + яд → `яд входит глубже лезвия`, `находит шов между пластин`;
  - Лук + лёд → `холод идёт поверху`, `ледяной наконечник крошится`.

Примеры для Громуна (тупик дальнего боя):

- Резист (арбалет+огонь): *«Едва. Камень смеётся над стрелой — гарпун отскакивает, искра гаснет.»*
- Уязвимость (клинок+огонь, после смены): *«Точно. Клинок находит щель между пластин, огонь идёт внутрь.»*
- Нейтрально (клинок без руны): *«Клинок попадает в плечо, оставляет засечку.»*

#### 8.8.4 Совместимость

| Решение | Связь с D19 |
|--|--|
| D13 (Старик = soft hint) | Хроника и совет Старика работают пре-боем; D19 добавляет внутри-боевую обратную связь, дополняя их |
| D16 (След = пре-боевая разведка) | Не пересекается: след читается до боя, D19 — внутри |
| D17 (Хроника гильдии) | Хроника тоже пре-боевая; D19 страхует тех, кто её пропустил или неправильно интерпретировал |
| §4.x описания видов | Источник лексики `{носитель}` и базовых глаголов; переиспользование согласовано с миром |
| §15.10 п.31 «Совет — не подсказка, а опыт» | D19 следует той же философии: не подсказывает действие, а отражает факт. Решение остаётся за игроком |

#### 8.8.5 Финальный статус §14.1

Открытый вопрос §14.1 «Стены чтения» **закрыт**. Внутри-боевые подсказки реализуются через нарратив, без новых сущностей и UI.

Зависимости:

- D19 требует небольшого расширения пулов прозы §§4.x и, возможно, нового блока категорий реакций (резист / уязвимость / нейтрально). Это задача продакшена текстов, не дизайна.
- D19 не меняет правила §4.x «Адаптация: после 5 раундов» — это по-прежнему механика давления. D19 просто помогает игроку заметить тупик до этого момента.
- D19 не меняет must-buy Арбалета, состав A-narrowed или архитектуру экономики.
